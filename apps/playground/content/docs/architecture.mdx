## Monorepo shape

```
trazo/
├── packages/trazo/          # THE ENGINE (publishable library)
│   └── src/
│       ├── index.ts         # layout(), layoutFlow(), layoutGit(), measure()
│       ├── types.ts         # Public contract: FlowGraph, CommitGraph, PositionedGraph
│       ├── layout-git.ts    # Git DAG → lane layout
│       ├── layout-flow.ts   # Flow graph → Sugiyama layered layout
│       ├── geometry.ts      # Shapes, anchors, edge paths, label sizing
│       ├── measure.ts       # Pure text measurement (bundled glyph table)
│       └── react/graph.tsx  # Pure SVG renderer (SSR-safe)
│
└── apps/playground/         # Next.js inspector app
    └── src/
        ├── app/             # Next.js App Router
        ├── components/      # Inspector, GraphViewport, UI kit
        └── lib/             # DSL parsers, fonts, utils
```

## Data flow

```
DSL source (text)
  ↓ parseDsl() / parseFlow()
CommitGraph / FlowGraph
  ↓ layoutGit() / layoutFlow()
PositionedGraph          ← pure TypeScript, no DOM
  ↓ <Graph />
<svg> element            ← React Server Component or hydrated client
```

## Design principles

**Determinism** — Equal input → equal `PositionedGraph`. No `Math.random`, no `Date`, no hash-map iteration order in any layout decision. Every tie-break is a fixed function of input array index.

**Purity** — The engine and renderer have no side effects. They don't read from `window`, `document`, or `navigator`. This makes SSR trivial: run the same code on server and client, get the same output.

**Engine owns geometry** — All coordinates, edge paths (as SVG `d` strings), and label sizes are resolved by the layout engine. The renderer (`<Graph>`) is a trivial pure function that maps `PositionedGraph` → `<svg>`.

**Token keys, not colors** — The engine emits `"lane-0"`, `"role-primary"`, etc. The renderer maps those to CSS variables. This keeps color decisions in one place and keeps the core environment-agnostic.

## SSR + hydration

The playground server renders the seed diagram into the initial HTML. The `<Inspector>` client island hydrates with the same `initialGraph` (pre-computed on the server). First client render is byte-identical to the server HTML — no hydration mismatch, no flicker.

```
Server: parseDsl(seed) → layoutGit(…) → <Graph /> → initial HTML
Client: Inspector hydrates with initialGraph → first render == server HTML
User edits → recompute in browser → update <Graph />
```

## Text measurement

`measure(text, fontSpec)` reads a bundled glyph-advance table for Public Sans (the JOYCO body font). No canvas, no DOM. Unknown glyphs fall back to the table's average advance. Re-generate the table with `pnpm --filter @joycostudio/trazo gen:glyphs`.
